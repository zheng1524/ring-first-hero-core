# Known limits

1. **Ring symmetry.** A circular torus does not independently fix yaw and may leave a normal-branch ambiguity. `RING_ONLY_YAW_UNRESOLVED` is a result, not a six-degree-of-freedom camera certification.
2. **Conditional cameras.** The actual full-pose path uses a real SIFT reference map and historical canonical cameras. Descriptor-held tracks do not remove all ancestral dependencies. Camera qualification is conditional engineering evidence, never absolute pose GT.
3. **Ceres scope.** Some frozen source cameras include the historical selected-subset joint refinement. The target CLI reproduces the RF/RGB initial solve; it does not reimplement full video-map construction or full trajectory Ceres optimization. Frozen support poses are kept and explicitly identified.
4. **Version metadata correction.** The previously reported MVSAnywhere `4483e25…` belongs to the parent research repository. The release verifies the actual used code against upstream `5bd49bba…`, file by file. The claimed commit is recorded as invalid, not marked PASS.
5. **Missing module registry.** `docs/registry/REUSABLE_MODULES.md` does not exist at the supplied snapshot or the inspected source worktree. T14–T20 labels cannot be authenticated. Actual functions and frozen file receipts replace neither those missing labels nor their unknown intended descriptions; they provide an explicit audit trail.
6. **HERO geometry quality.** The model may produce boundary stretching, wrong depth layers, Ring-near adhesion and disagreement between sources. Official pretrained weights and pixel/metric consistency do not establish anatomical accuracy.
7. **Raw geometry is preserved.** In the reproduced G01 Raw Mesh, 160 faces have at least one signed sample inside CAD, with minimum signed distance about −0.462 mm. There are 1,106 boundary edges, no nonmanifold edges in this sample, and 300 native vertices without surviving triangles under the original depth-jump rule. No defect was repaired or hidden to improve the release result.
8. **Cleaning is internal evidence.** Trusted/Uncertain/Rejected/Unknown are the unchanged017 proxy labels, not physical truth. Unknown is not an error. Conservative cleaning retains Unknown; the separately exported Trusted subset provides less surface. Neither fills holes or moves vertices.
9. **Visible surface only.** A native open mesh does not reconstruct a complete polyp, its unseen base or its hidden back side. Cumulative source areas are not unique anatomical area. No Dxy/height/volume measurement module or global fusion is added.
10. **Coordinate prior.** The historical adapter's Ring-world camera convention and official model preprocessing are retained exactly. No new ScanNet/world reorientation was silently introduced to make output look better. Other capture settings require independent validation.
11. **Reproducibility scope.** One G01 target with three original supports was actually rerun; G03 figures/GLB are clearly marked frozen reference sources. Different GPU/software implementations can change floating-point results. The measured bitwise identity on this workstation is not a guarantee for every device or dataset.
12. **Environment and access.** Core commands were tested using a new project environment with explicitly reused read-only dependencies. A clean new-host CUDA installation was not completed. Real inputs remain controlled and weights remain upstream; the repository does not claim to contain them.

Absolute camera and three-dimensional geometric accuracy are `NOT_EVALUABLE` without approved independent truth. The release is an engineering handoff of a research mainline, not a clinical validation or a solution to the known multi-source conflict problem.
